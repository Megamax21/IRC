IRC NOTES:

mot de passe du server : 1234

Server : reçoit la ligne brute, identifie la commande, vérifie que le client est enregistré.
Commands : découpe les arguments et applique les règles IRC.
Channel : modifie son propre état et expose des méthodes simples.
Client : représente l’utilisateur connecté.
Broadcast : diffusion à plusieurs machines en même temps
(ex: on envoie un message à plusieurs membres en même temps)

CHANNEL:

Un channel contient :
- un nom (ex: #general)
- une liste de membres
- une liste d'opérateurs
- +k, +i, +t

Pour contenir les Channels dans le Server, on utilise
une MAP qui permet la recherche par clé, efficace dans
notre cas car chaque channel possède 1 name

COMMANDES IRC:

join:
Quand un client envoie JOIN #salon, le serveur doit :
- vérifier que le format du channel est valide
- créer le channel s’il n’existe pas
- vérifier les restrictions du channel
- ajouter le client au channel
- si c’est le premier membre, le rendre opérateur
- envoyer les réponses IRC attendues, notamment le topic et la liste des membres

le client peut rejoindre plusieurs channel en même temps via join :
/join #a,#b,#c

Si le channel n’existe pas, le premier utilisateur qui rejoint le crée et devient opérateur.
Si le channel est +i, il faut une invitation.
Si le channel est +k, il faut la bonne clé.
Si +l est actif, il faut vérifier la limite de membres.

les réponses IRC ont cette forme :

:server NUM nick channelName :message

ex: :ircserv 475 Bob #secret :Cannot join channel (+k)

CODES IRC
461 : paramètres manquants
403 : canal inexistant ou nom invalide
471 : canal plein
473 : canal en mode invite-only
475 : clé incorrecte

privmsg:

/privmsg #channel message 
pour un privmsg envoyé dans un channel

/privmsg nickname :message
pour un privmsg envoyé a un utilisateur*

-> l'expéditeur ne voit pas son propre message lorsqu'il fait un privmsg
(comportement classique de hexchat)

kick:

KICK <channel> <nick> [<reason>]
ex: KICK #a sarah OU KICK #a sarah :spam

le serveur doit envoyer à tous les membres du channel puis retirer sarah du channel
:alice!alice@localhost KICK #a sarah :spam\r\n

le message KICK doit être reçu par tous les membres du channel, 
y compris la personne kickée

invite:

/invite <nick> <channel>
ex: INVITE sarah #a

le serveur doit envoyer :
- à sarah : 
:alice!alice@localhost INVITE sarah #a\r\n

- à alice :
:ircserv 341 alice sarah #a\r\n

- à sarah (si le channel a un topic)
:ircserv 324 #a +i ...\r\n

puis sarah peut rejoindre avec JOIN #channel
(même si le channel est en mode +i)
